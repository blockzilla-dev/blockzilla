# Code of conduct

Blockzilla welcomes contributors with different backgrounds and levels of
experience. This policy applies to project issues, pull requests, discussions
and other project spaces.

## Expected behavior

- Treat people with respect. Discuss the code and evidence, not the person.
- Make room for questions and constructive disagreement.
- Give useful feedback and accept corrections.
- Respect privacy and keep private reports confidential.

Harassment, threats, discrimination, sexual harassment, deliberate disruption,
and publication of another person's private information are not acceptable.

## Reports and enforcement

The project maintainer responsible for this policy is
[@augustin-cheron](https://github.com/augustin-cheron). Maintainers can remove
content, end a discussion, limit participation or exclude a contributor when
needed to enforce this policy.

For a private report about project content, use GitHub's **Report content**
menu and select **Report to repository admins** when that option is available.
Otherwise, use the [Report abuse process](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
to contact GitHub Support. A report about a maintainer can go directly to
GitHub Support. Do not post private evidence in a public issue.

Maintainers should apply this policy consistently and consider the facts and
impact of each report. Good-faith reports must not lead to retaliation.
